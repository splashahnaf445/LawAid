# LawAid Web Prototype

## Run the project
1. Extract the ZIP file.
2. Open the `LawAid` folder in VS Code.
3. Install/use the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.

## Public website pages
- `index.html` — Landing page
- `services.html` — Services page
- `features.html` — Features page
- `contact.html` — Contact page
- `role-access.html` — Role selection page

## Portal pages
- `client/` — Client login and client workspace pages
- `lawyer/` — Advocate login, registration, and workspace pages
- `admin/` — Admin login and administration pages

## Styles and images
- `assets/css/home.css` — Landing page styling
- `assets/css/public-pages.css` — Services, Features, and Contact page styling
- `assets/css/role-access.css` — Role selection styling
- `assets/css/admin-login.css` — Admin login styling
- `assets/css/client/`, `assets/css/lawyer/`, `assets/css/admin/` — Portal styling
- `assets/img/` — Images used by the website

## Prototype notes
This is a front-end prototype. The contact form shows a confirmation message in the browser but does not send email because no backend/email service is connected. Login forms and portal links are demonstration navigation and do not authenticate users unless connected to a backend.
