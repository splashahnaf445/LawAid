# UI/UX Prototype

High-fidelity prototype designed in **Figma**, with supporting visual assets in **Canva**. Roles covered: **Client**, **Lawyer** and **Admin**.

## Design system

| | |
|---|---|
| **Primary colors** | Dark navy and blue tones: professionalism, trust, reliability |
| **Secondary colors** | White and light neutrals: readability, clean surfaces |
| **Accent colors** | Orange / yellow for key buttons, highlights and calls to action |
| **Typography** | Bold headings for hierarchy · simple sans-serif body text · clear button/label text |
| **Layout** | Top navigation for the public site, sidebar navigation for dashboards · card-based interface · responsive across desktop, tablet and mobile |

### Principles followed
**Simplicity & clarity** · **Consistency** (navigation, buttons, colors, icons, cards, type) · **Accessibility** (readable sizes, contrast, clear icons) · **User feedback** (confirmations, status indicators, notifications) · **Role-based design** (separate client and lawyer interfaces)

## Key screens by module
- **Client:** landing page, verified lawyer search, lawyer details, appointment booking, consultation scheduling, online consultation, case management, messaging, profile/settings, notifications
- **Lawyer:** dashboard, client management, case management, consultation management, appointment management, messaging, profile/settings, notifications
- **Admin:** dashboard, user management, lawyer verification, client/lawyer management, case and consultation management, appointment management, legal service management, reports and analytics, notifications, content management, system settings

## Navigation flow
1. Users start at the **landing page**
2. After login they reach their **role-based dashboard**
3. From the dashboard they use the **navigation menu / sidebar** to reach features
4. Every section links back to the dashboard and related sections
