## System study
**Internal sources:** general clients seeking legal help, and practicing lawyers (scheduling, document handling, payment tracking challenges).
**External sources:** benchmark of UkilBD, FindMyAdvocate, PathLegal (Bangladesh), LawRato (India) and DoNotPay (USA).
